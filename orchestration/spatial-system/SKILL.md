# Spatial System

Create a scene location map and per-shot spatial slice. Establish one coordinate convention, fixed landmarks, actor/prop anchors, 180-degree axis, eyelines, entry/exit paths, foreground/midground/background, and any useful normalized screen coordinates. Treat reference framing as non-binding unless explicitly inherited. Detect contradictions before shot lock; do not write performance or final prompts.

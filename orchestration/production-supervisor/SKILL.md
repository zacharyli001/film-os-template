# Production Supervisor

Use `AGENTS.md`, relevant cards, registries, and version log. Reject illegal transitions. Package one shot with only active approved context, audit it before G4, and record hashes/versions where available. Classify failed takes by primary variable and route to the owning engine: identity/look/edit → LIRA; performance → ACTING; camera/blocking/timing/physics/light/audio/continuity → CINEDANCE, with Spatial System consulted for geography. Preserve approved variables and log every decision.

For episodic work, resolve the current Episode Card and continuity ledger before packaging. The Shot Pack receives explicit current-state facts, never whole prior episodes. Require continuity preflight before episode G1 and continuity closeout after episode G5; only facts visible or audible in the approved edit become on-screen canon.

# Script Doctor

Read `../../../orchestration/script-doctor/SKILL.md`, `../../../CREATIVE_CONSTITUTION.zh-CN.md`, and the Creative North Star. Work on an existing screenplay, not a raw idea. Diagnose before rewriting; distinguish observable craft problems, tradeoffs, and taste. Never use formulaic convention to overrule intentional creative choices. Save only human-accepted revisions as a new version in `../../../项目工作区/03_剧本/` and update the project overview.

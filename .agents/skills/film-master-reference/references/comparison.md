# 名家参考选择与组合

只有人明确要求比较或组合时读取本文件。默认使用单一参考，以免多种风格共同稀释作品自身的声音。

## 快速选择

| 当前问题 | 优先参考 | 主要借用机制 |
|---|---|---|
| 群像人物困在同一生活状态，冲突不适合集中到反派 | 契诃夫 | 环境压力、分布式欲望、错位对白、余波结尾 |
| 家庭成员离开或关系安静重组 | 小津 | 事件前后、中转关系、回响物件、递减尾声 |
| 权力群像、多线竞争、公共大场面或连载引擎 | 《继承之战》 | 目标碰撞、程序容器、信息限制、阵营重画 |
| 大事件不宜直接表现 | 契诃夫或小津 | 契诃夫偏群体继续生活；小津偏家庭余波和空间缺席 |
| 剧集季终过于碎片化 | 《继承之战》 | 减少场景、延长结算、明确权力转移 |
| 对白太解释、太完整 | 契诃夫或小津 | 契诃夫偏错位与打断；小津偏日常表层与间接承认 |

## 可控组合

### 契诃夫 × 小津

适合安静群像、家庭衰败和时间侵蚀。共同点是弱化事件中心、强化日常与余波；区别是契诃夫更强调多人无法互相抵达，小津更强调家庭秩序改变后的空间与礼节。组合时只选一个主要结构来源，另一个只提供场景或结尾工具。

### 契诃夫 ×《继承之战》

适合表面平静、内部权力激烈的组织或家族。用《继承之战》建立清楚的目标、资源和程序压力，用契诃夫减少反派化、保留人物自欺和无法完成的情感。避免把每场戏同时写成高密度权力交锋。

### 小津 ×《继承之战》

适合把宏观权力后果落回家庭日常。用程序容器推动事件，用小津式余波、物件和空间表现私人代价。两者节奏密度差异很大，应明确哪些段落负责压力、哪些段落负责沉淀。

## 输出限制

组合建议必须明确：

- 主参考是什么；
- 次参考只解决哪个局部问题；
- 用户作品原有的哪些特质必须保留；
- 哪些表面特征明确拒绝复制；
- 一次试验应用在哪一场或一个段落；
- 如果失败，怎样无损撤回。

不要创造“契诃夫 40%＋小津 30%”之类虚假精度，也不要把参考名称写进正式视频 Prompt。

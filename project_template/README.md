# 作品项目骨架（仅供母版生成器使用）

这里保存 Film OS 新建作品时需要展开到独立生产仓库的项目资料骨架。

## 重要边界

- 这里不是 Film OS 母版的通用规则区。
- 这里不是任何真实作品的正式资料区。
- 不在这里开发通用 Skill、通用流程或升级工具。
- 新项目建立时，`tools/create_project.py` 会把本目录内容展开到新作品仓库的根目录，然后不会把这个包装目录带入作品仓库。
- 之后 Film OS 升级只管理母版系统文件，不会把本目录覆盖到已经存在的作品资料。
- `governance/` 保存项目专属的导演权限；`submissions/` 保存成员只能新增的提案子线。这两个目录在作品项目中都属于受保护资料。

真实作品的剧本、资产、审批、分镜和 TapNow 记录必须放在由 `$film-project-launcher` 创建的独立作品仓库中。

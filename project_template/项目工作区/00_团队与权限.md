# 团队与权限

## 导演

- 姓名：待填写
- GitHub 用户名：以 `governance/AUTHORITY.yaml` 为准
- 本地导演钥匙：由系统建立，只保存在导演电脑，不上传或分享
- 最终决定范围：核心概念、主题、人物、结局、整体视觉、最终成片
- 独占权限：正式仓库写入、主线归整与发布

## 主创

- 主创指除导演之外的所有人员。三人模式下包括成员 A、成员 B。
- 主创身份不等于导演权限；只有导演端可以归整和发布正式主线。

## 全员固定边界

- 非导演成员可以读取全部正式资料，但不能修改、删除、重命名或覆盖任何已有文件。
- 免费 GitHub 模式下，成员不获得导演正式仓库写权限，通过各自交付仓库提交独立提案分支；没有交付仓库时，再提交完整成员包。
- 成员只能在 `submissions/本人GitHub用户名/带UTC时间的提案ID/` 新增内容。
- 基于未批准提案产生的剧本、分镜、资产、Prompt 和 TapNow 记录必须留在同一提案包。
- 部门确认、AI 输出和生成成功都不能让提案成为正式主线；只有导演可以归整和发布。

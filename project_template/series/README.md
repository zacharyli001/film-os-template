# Series workspace

Codex maintains this folder automatically for episodic projects. Team members work through Film OS department chats instead of editing YAML by hand.

```text
series/
  SERIES_BIBLE.yaml
  SE01/
    SEASON_MAP.yaml
    episodes/
      SE01_E001/
        EPISODE_CARD.yaml
        screenplay_v01.md
        scenes/
          SE01_E001_S001/
```

Permanent show rules live in the Series Bible. Season plans live in the Season Map. One Episode Card owns each episode's promise, hook, state changes, threads, assets, scenes, and five scoped gates. Approved on-screen facts are closed into `registry/SERIES_CONTINUITY.yaml` before the next episode reaches script lock.
